# Capitec Pay via Peach Payments

## Enablement Steps

1. Log in to Peach dashboard
2. Navigate to Payment Methods
3. Enable Capitec Pay (1.50% + R1.50 per transaction — see https://peachpayments.com/capitec-pay-merchant-list)
4. Confirm it appears on a test checkout
5. Complete R1 live verification
6. Note the completion in OpenBrain

## Notes

- **No code change required** — checkout automatically renders whatever payment methods Peach enables
- This is a pure payment-completion win for Capitec-banked customers
- Settlement terms: next-business-day via existing Peach integration
